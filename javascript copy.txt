    Both setTimeout and setInterval are built-in timing functions in JavaScript, but they differ in how often they run:

    setTimeout: Executes a function once after waiting for a specified delay (in milliseconds).

        setInterval: Executes a function repeatedly at fixed time intervals until stopped.

        JavaScript

        // 1. setTimeout - Runs ONCE after 2 seconds (2000 ms)
        const timeoutId = setTimeout(() => {
        console.log("Executed once after 2 seconds!");
        }, 2000);

        // Stop timeout before it runs:
        clearTimeout(timeoutId);


        // 2. setInterval - Runs REPEATEDLY every 1 second (1000 ms)
        const intervalId = setInterval(() => {
        console.log("Executed every 1 second!");
        }, 1000);

        // Stop interval when needed:
        clearInterval(intervalId);

        Key Takeaway: Use setTimeout for a delayed single action (like showing a notification) and 
        setInterval for recurring updates (like a live digital clock).
